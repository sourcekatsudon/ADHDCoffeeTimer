# ADHD Coffee Time v0.2.0 ☕

## 日本語 / Highlights

タイマーを忘れる人のための、操作しなくても動くデスクトップタイマーに、**自動稼働履歴**と**任意のGoogleアカウント同期**を追加しました。

- **自動稼働履歴**：タイマーが動作中の秒数を記録。離席・一時停止中はカウントしません。
- **履歴の可視化**：タイマー上に直近3日間、ポップアップに7日間を15分単位で表示。セルの消去にも対応。
- **完了のフィードバック**：タイマーが完了すると、該当の履歴セルをやさしくハイライト。
- **複数PC同期（任意）**：[Webダッシュボード](https://adhd-coffee-focus.vercel.app/)でGoogleログインし、PCごとのワンタイムコードで連携。Web上で7日／30日の履歴を集計表示。
- **ローカル保持**：新バージョンでは最大32日分の履歴を保持。オフラインでもタイマーと履歴が使えます。
- **省電力化**：描画更新を軽量化。CPU使用率0.6%は目標値であり、ハードウェア上で保証・検証された値ではありません。

### Installation

Download the matching **Windows x64 installer** or **macOS Intel / Apple Silicon DMG** from this release. Existing v0.1.0 users should install v0.2.0 to get focus history and cloud sync. Prior activity that was never recorded cannot be recovered.

The desktop app works without an account. Cloud sync is **opt in** and starts only after pairing each PC. It uploads aggregated activity time slots, not keystrokes, screen captures or work contents. Overlapping activity from two PCs may be approximate.

**Important platform limits:** Windows installers are not code-signed, so SmartScreen may warn. macOS builds have ad-hoc signing and are **not Apple-notarized**; Gatekeeper may require an explicit approval on first launch. Native Mac operation has not been manually tested on physical Macs as part of this release process. Linux builds remain unavailable.
